# Virtualization

The local VibeVirtual repository was empty during this integration. No virtualized sorting example or supported VibeVirtual API is advertised.

Dnd-kit collides against registered mounted elements. An offscreen unmounted row has no measured target. Stable IDs alone do not provide offscreen insertion positions. Removing the active source cancels its operation in VibeDND.

A future integration needs a persistent drag source or engine-supported source representation, mounted sentinel zones, deliberate overscan, scroll-to-index behavior, and a verified mapping from virtual positions to canonical indexes. Keep the virtualizer optional and use its public API. Do not claim virtualized transfer support from a short nonvirtual list.
