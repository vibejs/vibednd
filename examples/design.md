# Showcase design

The subject is a product team's release board, aimed at application developers evaluating drag and drop. Its primary job is to make moving real work feel precise.

Palette: ink #172335, canvas #f7f9fc, blue #4568e8, mist #edf1f8, mint #25836a, amber #b56b12. Display: Avenir Next, used in the project heading. Body: system UI. Utility: ui-monospace for task identifiers and key hints. Dark mode uses a navy canvas and the same semantic colors.

Layout: a quiet 208px navigation rail, a slim utility header, and a generous work area. The signature is the colored progress rail along each column heading, encoding actual workflow status. The board itself opens the product, so users can immediately try the library. Avoid a generic marketing hero; documentation and examples sit beside the board.
