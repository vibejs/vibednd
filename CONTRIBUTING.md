# Contributing

Use pnpm and a supported Node version. Keep all adapter imports on public package entry points. Run the unit, template type, browser and packed consumer checks before submitting a change. A change to sorting must retain the keyed-DOM regression suite and explain data ownership.

Use Conventional Commits and add a Changeset for user-visible changes. Do not add attribution trailers. Keep changes focused and preserve unrelated files. Never publish, push, deploy or create remote resources as part of a local check.

Performance results must state the browser, environment, input pacing and workload. DOM accessibility checks are distinct from manual screen-reader verification. Known limitations belong in the docs and delivery report.
